# PSF Education and Outreach Workgroup 

The Education & Outreach Workgroup's (EOW) purpose is to support the Python Software Foundation’s mission to promote the Python programming language, especially in supporting and enhancing the education of Python.

[Our charter](https://wiki.python.org/psf/working-groups/Python%20Edu%20Charter.html)

## Projects

### Guild of Educators (GOE)

The Guild of Educators is a free and open community for people who teach or are interested in teaching software development. We share resources, red books together and are open to allowing new people to step in and add value to the community by brining their own ideas and initiatives.

- Where: [Guild of Educators Discord](https://discord.gg/8cPdX2bAze)
- [Website](https://guildofeducators.org)
- [Website repo](https://github.com/Guild-of-Educators/website) Note that the website is being rebuilt, so the repo is still quite bare


### Organisers' Toolkit

The Python Software Community and Conference Organizers Kit is a comprehensive resource developed by members of the Python Software Community to support individuals and groups in organizing Python-related events and fostering local communities. Adapted from materials by PyLadies Global, this kit offers practical guidance for both new and experienced organizers.

- [Website](https://psf.github.io/organizer-toolkit/)
- [Repo](https://github.com/psf/organizer-toolkit)


### PyCon Education Summit 

The Education Summit is a one day event that happens during PyConUS. It existed before the Education and Ourtreach Workgroup was relaunchd. We are primarily assisting with planning and running the event. 

We are also putting effort into documenting the education summit so that others can get involved more easily, and so that the event can be replicated in other parts of the world.

It is a very impactful event, we'd like more of that!
